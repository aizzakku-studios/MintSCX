# SCX; What does it mean?
SCX is an interpreted custom language within scratch 3 (SB3).<br>
It has a pretty simple syntax and it is easy to learn.<br>
`SCX native // name of lang`<br>
`Say,variable;`<br>
This code says the output of the variable 'variable'.<br>
The format is:<br>
name,inputs;<br>
It is as easy to learn as SB3 and right now it has around 40 usable commands (at the time of writing) with as much as 6 inputs.<br>
It is created by me and I learned to use it and made it all by myself.<br>
You can make variables by using normal SB3, variables are removed before starting the project so it doesnt have bugs.<br>
The language includes features from C, if you dont write a semicolon the line of code just doesnt run forever and it breaks the entire project (not literally, just doesnt run forever until restart).
